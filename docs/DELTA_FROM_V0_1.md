# 相对原稿 v0.1 的修订依据

原稿：`EulerPilot/docs/v2_redesign_2026.md`，2026-10-19；本项目保存完整输入快照，不原地覆盖。修订日期：2026-10-21。

| 原稿设计/判断 | v0.2 决定 | 依据和影响 |
|---|---|---|
| SP4主环境，SP3代码兼容；推测赛题文案过期 | SP3完整闭环与性能为硬门槛 | 用户赛题明确SP3；本地已有SP3 scx构建/小样本证据，不能自行变更要求 |
| SP3不含sched_ext，必须回移6.12 | 先核对准确SP3源码/config/BTF | SchedPilot记录只启用配置即构建运行；实现缺失与发行内核未启用不同 |
| BASIC接近默认，NORMAL默认BASIC | BASIC/fair各自实测；idle状态由quiet预算决定 | SchedPilot noif-2 BASIC约-5.67%吞吐；不是零成本 |
| “五类自动分类”包含BG | 行为四态×显式角色 | 旧BG主要显式标记；运行特征无法推断业务重要性 |
| 100ms采样/分类/路由/参数写入 | 分离采样、分类、参数变更、心跳 | 减少抖动与观测成本，驻留窗口支持可解释反馈 |
| Agent为唯一写map者 | 特权执行服务唯一写，Agent提交计划 | 防CLI/loader/daemon双写；所有权需真实FD与fencing |
| generation保证一致性 | 增加bank发布与内核可见性验证 | 单字段不能原子更新多个map；旧排队任务也需切换协议 |
| Agent失效自动静态安全参数 | 修复所有模式的slice/class/BG/vtime失效行为 | 旧心跳检查并非完整参数恢复；静态模式仍可能饥饿 |
| 跨域失败整体原子回滚 | WAL+saga补偿+reconcile，暴露恢复失败 | cgroup/TC/BPF无跨域原子机制，已丢包/OOM不可逆 |
| 选或生成意味着必须生成 | 选择为必需主线，DSL生成做可验证增强 | 赛题是“或”，LLM/MCP也未强制要求 |
| MoE/bandit本身作为创新 | 引用MoS/SchedCP，研究受约束路由与可靠发布 | 同类机制已有工作；MoS实际是离线学习路由，不能误称在线bandit |
| 大幅QPS提升证明系统更优 | 加fair+cgroup强基线、BG进度、相同资源预算 | 区分资源倾斜与数据面/Agent增益，披露业务保护代价 |
| 固定C旧数据与D新数据比较 | 同一最终构建重跑C/D直接配对 | formal-5只含A/D，不能用跨构建结果论证D>C |
| 模拟器验证性能安全 | 回放只验证逻辑，隔离pilot验证效果 | 离线trace不能重现策略改变后的缓存/锁/请求链因果 |
| 前端简化或重写 | 舍弃旧验收前端，先做CLI和实验 | 用户本轮已明确确认；旧文件仍在原项目，新项目不迁入 |
| 8–10周假设，最低版可无扩展真实链路 | 按阶段门槛排期，最低版含真实hook扩展证明 | 截止时间未知；空Skill接口不足以证明可扩展执行 |

保留的主要方向：独立重做、模块化复用SchedPilot、精简EulerPilot治理层、规则优先/学习可选、声明式策略、可复现实验与负结果披露。细节分别见主方案、两份代码审计和一手来源核验。
