EulerPilot v2 — cfg parameter writes — SP3 evidence
Recorded 2026-10-21 on schedpilot-sp3 (<SP3-IP>)

Component
  ep-schedctl (GPL-2.0, sched/schedctl.cpp) is a short-lived helper invoked by
  the executor. It opens the pinned cfg map, applies policy parameters, bumps
  cfg.generation, reads back and verifies. It is not a long-lived second writer.

Parameter mapping
  policy spec.parameters.lat_slice_ns            -> sp_cfg.lat_slice_ns
  policy spec.parameters.comp_slice_ns           -> sp_cfg.comp_slice_ns
  policy spec.parameters.cache_slice_ns          -> sp_cfg.cache_slice_ns
  policy spec.parameters.bg_slice_ns             -> sp_cfg.bg_slice_ns
  policy spec.parameters.preempt_threshold_ns    -> sp_cfg.preempt_thresh_ns
  policy spec.parameters.bg_vtime_pct            -> sp_cfg.bg_vtime_pct
  policy spec.parameters.llc_affinity            -> SP_FLAG_LLC_AFFINITY bit

Lifecycle
  apply    -> attach, pin, cfg_before=get, set(parameters), cfg_after=get,
              verify re-reads cfg and compares
  rollback -> restore(cfg_before) while the loader is still attached, then
              SIGTERM/detach, then remove owned pins
  crash    -> runtime marker stores cfg_before; recover_orphan restores it
              before stopping the orphan loader
  failures -> a failed set restores cfg_before and stops the loader; a restore
              failure is reported in the rollback detail after detach
