EulerPilot v2 — helper budget / EOF / pin ownership — SP3 evidence
Recorded 2026-10-22 on schedpilot-sp3 (<SP3-IP>)

Fixes
  - refresh now carries an absolute deadline derived from
    min(now+500ms, lease expiry, policy TTL expiry); each helper call gets
    min(remaining budget, ctrl_timeout_ms), and the first failure stops the
    whole round (no 3x200ms serial accumulation).
  - run_ctrl uses one absolute deadline for output and reap; the old
    deadline+1s EOF grace is removed. Helpers run in their own process group;
    timeout kills the group and reaps with a bounded grace.
  - receive_link_fd bounds the post-accept wait with the same startup deadline
    and uses MSG_CMSG_CLOEXEC | MSG_DONTWAIT.
  - abort_attach uses the pin set captured at attach time (not list_pins()),
    checks detach/stop results, and cleanup_pins preflights every pin before
    deleting any; a foreign/replaced pin aborts the cleanup and leaves the
    context for recovery.
