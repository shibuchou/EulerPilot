Scope
  Read-only `slo.evaluate` / `ep slo --expert NAME`. It answers whether the
  current FeatureWindow permits an expert. It never writes the scheduler.

Checks
  - expert must be known (safe-basic / latency-balanced / throughput-balanced /
    cache-local);
  - FeatureWindow must have >=3 samples and age <= max_observation_age_ms;
  - cpu_busy_pct must be valid;
  - latency-balanced/throughput-balanced require valid PSI;
  - throughput-balanced is denied when PSI some avg10 >= 20;
  - cache-local is denied because LLC/topology is not sampled;
  - safe-basic is allowed without PSI (conservative fallback);
  - quiet regression is reported as not evaluated (no quiet baseline yet).

Unit cases
  - all invalid -> FEATURES_INSUFFICIENT
  - psi=30 + throughput-balanced -> PSI_PRESSURE_TOO_HIGH
  - psi=30 + latency-balanced -> allowed
  - PSI missing + latency-balanced -> PSI_FEATURE_MISSING
  - PSI missing + safe-basic -> allowed
  - cache-local -> LLC_FEATURE_MISSING
  - age 5000ms > 1000ms -> FEATURES_STALE
