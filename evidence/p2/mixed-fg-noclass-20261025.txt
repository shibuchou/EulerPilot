class 分离——D 与 A0 的差别同时含调度器、expert 参数与观测栈。本轮补上缺口:

## 2. 结论

**联合 SLO 的改善不需要 class 分离**:去掉全部 class 声明后 Dnc 与 D 逐轮同级
(2/3,svc-B 唯一 miss 都是 2ms 擦线)。预算更紧的服务被救回来靠的是 expert 的
切片/预算参数作用在无分类路径上。至此三条独立证据线互证同一件事:
- B 臂:BASIC+观测 vs A0 = +1.75%(旗舰量级收益在 BASIC 形态就出现);
- class-routing 消融:Cc−C = 彻底的零;
- 本轮:Dnc ≈ D(mixed-foreground 的联合 SLO 改善与 class 无关)。

`spec.targets[].class` 的定位最终确定:**可声明/可审计/可撤销的契约,不是性能开关**。

边界:单机单负载;n=3;Dnc 与 D 的对比跨运行(不同日),逐轮数字相近但未做块内
配对;原轮 D 的数字引用自 2026-10-23 轮(旧构建),本轮 Dnc 用冻结构建——两边都是
"各自臂的原样形态",结论只用于归因方向,不用于量级精比。
